# Сценарий рилс

## Перед генерацией

1. Прочитать `core/red-lines.md` целиком и раздел 9.1 `core/system-prompt.md`.
   Без этого не начинать: роль редактора приезжает отсюда, а не из памяти.
2. Взять свободную тему: `python3 scripts/topics.py list`.
   Тему, которой нет в реестре, не брать — сначала обсудить с автором.
3. Фактуру брать из `core/transcripts/`. Своими словами дополнять можно,
   выдумывать факты, цифры и исследования нельзя.

## Генерация

4. Формат: `озвучка` для механизмов и разборов, `в_кадре` для личного и
   прямых обращений. Держать пропорцию около 60/40 в пользу озвучки.
5. Собрать по шаблону `core/templates/reels.md`, структура — раздел 9.1
   системного промпта.
6. Речь писать устным языком. Прочитать вслух: спотыкаешься — переписать.
7. Один материал — один тезис. Четыре темы в одном ролике не смешивать.

## Запись

8. Номер: `ls reels/*/ tg/*/ | grep -o '[rt]-[0-9]*' | sort -u | tail -1`,
   взять следующий. Файл — `reels/queue/r-NNN.md`.
9. Заполнить фронтматтер целиком. Поля `источник` и `требует_проверки` —
   всегда, `что_проверить` — конкретным вопросом, а не «проверить факты».
   Дата в `создан` — сегодняшняя.
10. Занять тему: `python3 scripts/topics.py take <тема_id> reels/queue/r-NNN.md`

## Проверка

11. Прогнать самопроверку раздела 13 системного промпта. Нарушение —
    переписать, не выдавать.
12. `python3 scripts/lint.py reels/queue/r-NNN.md`. Ненулевой код — чинить
    текст, а не глушить правило.
13. Правило глушится только когда материал разбирает миф и обязан его
    процитировать. Тогда во фронтматтер:
    `линтер_исключения: [гормональный-сбой]`, id берётся из
    `core/stop-words.txt`. Правила с «!» не отключаются никогда.

Показать автору путь к файлу и тезис одной строкой. В `review/` материал
переводит человек, не скилл.
