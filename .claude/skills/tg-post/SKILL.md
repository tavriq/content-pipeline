# Пост в Telegram

## Перед генерацией

1. Прочитать `core/red-lines.md` целиком и разделы 7 и 9.2
   `core/system-prompt.md`. Telegram — ядро: здесь глубина и лояльный
   читатель, а не верхняя часть воронки.
2. Взять свободную тему: `python3 scripts/topics.py list`.
3. Фактуру брать из `core/transcripts/`. Цифры и исследования — только
   атрибутируемые. Нет источника — переформулировать без цифры.

## Генерация

4. Собрать по шаблону `core/templates/tg.md`, структура — раздел 9.2
   системного промпта. Длина 800–2500 знаков.
5. Обращение на «вы». Короткие предложения, один абзац — одна мысль.
   Юмора нет. Эмодзи ноль-два, только функционально.
6. Если тот же инфоповод уже уехал в рилс — текст писать заново, не
   пересказывать сценарий. Один инфоповод, два разных материала.

## Запись

7. Номер: `ls reels/*/ tg/*/ | grep -o '[rt]-[0-9]*' | sort -u | tail -1`,
   взять следующий. Файл — `tg/queue/t-NNN.md`.
8. Заполнить фронтматтер целиком. `источник` и `требует_проверки` —
   всегда, `что_проверить` — конкретным вопросом.
9. Занять тему: `python3 scripts/topics.py take <тема_id> tg/queue/t-NNN.md`

## Проверка

10. Самопроверка по разделу 13 системного промпта.
11. `python3 scripts/lint.py tg/queue/t-NNN.md`. Ненулевой код — чинить
    текст, а не глушить правило.
12. Исключение линтера — только для разбора мифа, который обязан миф
    процитировать: `линтер_исключения: [гормональный-сбой]`.
    Правила с «!» в `core/stop-words.txt` не отключаются никогда.

Показать автору путь к файлу и заголовок. В `review/` переводит человек.
