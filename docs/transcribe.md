# Расшифровка голосовых

Живёт на сервере рядом с ботом. На маке ничего из этого не ставится и не
запускается.

---

## Как это выглядит для автора

Она пишет голосовое прямо в чат с ботом. Бот отвечает «принял, расшифрую
примерно за N минут», кладёт запись на сервер и через несколько минут
присылает готово. Расшифровка попадает в `core/transcripts/` и
синхронизируется в репозиторий сама.

Ей не надо ничего пересылать разработчику, ставить, открывать и называть
файлы.

---

## Движок

`faster-whisper` на CPU, модель `medium` в int8.

Почему не mlx, который быстрее: он работает только на Apple Silicon, а
расшифровка живёт на Linux-сервере. Один движок на обе среды дешевле, чем
два разных.

Скорость на двух ядрах — примерно в два-три раза медленнее реального
времени. Расшифровка идёт фоновой задачей: бот при этом отвечает на кнопки, записи
обрабатываются по одной.

Модель тянется с huggingface при первом запуске, около полутора
гигабайт, дальше берётся из кеша.

---

## Требования к серверу

| Что | Сколько | Почему столько |
|---|---|---|
| RAM | 4 ГБ | medium в int8 укладывается в лимит контейнера 3 ГБ вместе с ботом. Добавлен swap 4 ГБ для запаса |
| CPU | 2–4 ядра | меньше двух — расшифровка растянется впятеро |
| Диск | 25 ГБ | модель, репозиторий, голосовые, система. Взято 48 |
| Локация | не РФ | huggingface из России отдаёт около 30 байт в секунду, модель оттуда не приезжает |

`large-v3` на этом сервере не используется: на длинной записи она
превысила лимит контейнера 3 ГБ и была завершена OOM-killer. Для качества
медицинских терминов используется `initial_prompt` в скрипте.

Проверить, доступен ли huggingface с сервера:

```bash
curl -sL -o /dev/null -w "%{speed_download} байт/с\n" --max-time 20 \
  "https://huggingface.co/Systran/faster-whisper-medium/resolve/main/config.json"
```

Меньше сотни килобайт в секунду — модель придётся везти руками:
скачать репозиторий модели там, где он открывается, и положить в
`/var/lib/blog-cache/huggingface/hub/` на сервере.

## Запуск руками

Бот делает это сам, но иногда нужно прогнать напрямую:

```bash
python3 scripts/transcribe.py core/voice/2026-08-05.ogg
python3 scripts/transcribe.py core/voice            вся папка
python3 scripts/transcribe.py файл --timestamps     строки с таймкодами
python3 scripts/transcribe.py файл --force          перезаписать
python3 scripts/transcribe.py файл --model small    временно снизить нагрузку
```

Результат — `core/transcripts/<имя>.md`: фронтматтер с длительностью и
моделью, дальше текст абзацами по паузам в речи.

Скрипт сам перезапускается под `.venv`, вызывать можно обычным `python3`.

---

## Если качество хромает

- диктовать в тишине: шум сажает качество сильнее, чем выбор модели;
- термины и фамилии проговаривать отчётливо;
- список терминов лежит в `PROMPT` внутри `scripts/transcribe.py` —
  дописывать туда те, что модель стабильно портит, по факту ошибок,
  а не превентивно.

Голосовые остаются на сервере и в гит не попадают — в репозитории живёт
только текст.
