# Стоп-лист красных линий. Источник правил — core/red-lines.md.
#
# Формат строки:  регулярка<два пробела># id | пояснение
#   регулярка — питоновский re, регистр не учитывается
#   id        — короткое имя правила, им правило отключается в материале
#   пояснение — попадает в вывод линтера
#
# Пустые строки и строки, начинающиеся с #, игнорируются.
# Фильтр тупой и ловит с запасом: лучше лишнее срабатывание, чем
# пропущенная публикация.
#
# Восклицательный знак в начале строки — правило неотключаемое.
# Это разделы 1 и 2 красных линий: статус автора, диагнозы, дозировки,
# препараты, обещания результата. Разбор мифа не требует их цитировать.
#
# Остальные правила отключаются точечно, по одному материалу, полем
# во фронтматтере:
#
#     линтер_исключения: [гормональный-сбой]
#
# Это нужно рубрике «разбор мифа»: тема «Почему диагноза "гормональный
# сбой" не существует» иначе не проходит собственный фильтр.

# ── 1. Статус автора — неотключаемое ──────────────────────────────
!как\s+(врач|эндокринолог|специалист|эксперт)\w*\s*,?\s+я  # как-врач-я | автор говорит от лица врача
!я\s*,?\s+как\s+(врач|эндокринолог|специалист|эксперт)  # я-как-врач | автор говорит от лица врача
!в\s+мо[ей][йия]\s+практике  # моя-практика | намёк на врачебную практику
!мо[йиея]\w*\s+пациент\w*  # мой-пациент | практики у автора нет
!на\s+при[её]ме\s+я  # на-приёме-я | намёк на приём
!запис[аьи]\w*\s+ко\s+мне  # запись-ко-мне | намёк на запись к автору
!я\s+назнача\w+  # я-назначаю | назначения делает врач, не автор

# ── 2. Диагноз, лечение, препараты — неотключаемое ────────────────
!у\s+вас\s+(скорее\s+всего|вероятно|похоже|наверняка|явно)  # заочный-диагноз | диагноз конкретному человеку
!по\s+ваш(им|ему)\s+(анализ|результат|ттг)\w*  # чужие-анализы | интерпретация присланных анализов
!ваш\w*\s+(ттг|т4|т3|пролактин|инсулин)\b  # ваш-показатель | интерпретация присланных анализов
!\d+[\d.,]*\s*(мг|мкг|мл|ме|ед|таб)\b  # дозировка | доза препарата
!\d+\s*раз[ауы]?\s+в\s+(день|сутки|неделю)  # режим-приёма | кратность приёма
!схем[аыу]\s+лечени  # схема-лечения | схема лечения
!курс\w*\s+при[её]ма  # курс-приёма | режим приёма
!(принима|пропит|попит|пить|пейте|выпейте|назнач|рекоменду)\w*(\W+\w+){0,4}\W+(левотироксин|тироксин|эутирокс|метформин|глюкофаж|йодомарин|дюфастон|утрожестан|мерказолил|тирозол)  # препарат-рекомендация | препарат в рекомендательном ключе
!(левотироксин|тироксин|эутирокс|метформин|глюкофаж|йодомарин|дюфастон|утрожестан|мерказолил|тирозол)\w*(\W+\w+){0,4}\W+(принима|пропит|попит|пить|пейте|выпейте|назнач|рекоменду)  # препарат-рекомендация-2 | препарат в рекомендательном ключе
!детокс  # детокс | запрещённая тема
!почистить\s+(организм|печень|кишечник)  # почистить | запрещённая тема
!чистк[аиу]\s+(печени|организма|кишечника)  # чистка | запрещённая тема
!протокол\w*\s+восстановлен  # протокол-восстановления | авторские протоколы
!(вылеч|излеч)\w*(им|ите|ится|иться|итесь)  # вылечим | обещание результата
!избав(им|итесь|ляет\s+навсегда)  # избавитесь | обещание результата
!уйд[её]т\s+навсегда  # уйдёт-навсегда | обещание результата
!гарантиру\w+\s+результат  # гарантия | обещание результата
!\bдо\s*/\s*после\b  # до-после | формат «до/после»
!фото\w*\s+до\s+и\s+после  # фото-до-после | формат «до/после»
!будет\s+рак\b  # будет-рак | запугивание
!вы\s+в\s+группе\s+риска  # группа-риска | запугивание
!уже\s+в\s+группе\s+риска  # группа-риска-2 | запугивание

# ── 3. Добавки и вес — отключаемое поштучно ───────────────────────
# Про добавки блог обязан говорить: это 20% контента и точка отстройки.
# Ловится только рекомендательная связка, и окно узкое — «объясняем, а
# не рекомендуем» срабатывать не должно.
(принима|пропит|попит|пить|пейте|выпейте|назнач|рекоменду)\w*(\W+\w+){0,2}\W+бад  # бад-рекомендация | добавка в рекомендательном ключе
бад\w*(\W+\w+){0,2}\W+(принима|пропит|попит|пить|пейте|выпейте|назнач|рекоменду)  # бад-рекомендация-2 | добавка в рекомендательном ключе
\bкалори  # калории | калории и производные
\bккал\b  # ккал | калорийность в цифрах
\bимт\b  # имт | ИМТ как цель
минус\s*\d+\s*кг  # минус-кг | целевая цифра веса
[-–—]\s*\d+\s*кг  # тире-кг | целевая цифра веса
\d+\s*кг\s+за\s+\d+  # кг-за-срок | «N кг за N недель»
топ[-\s]?\d*\s*продукт  # топ-продуктов | список продуктов
список\s+продукт\w*\s+на\s+день  # список-продуктов | план питания
план\w*\s+питания  # план-питания | план питания
интервальн\w+\s+голодан  # интервальное-голодание | протокол ограничения
монодиет  # монодиета | протокол ограничения
элиминационн\w+\s+(диет|схем)  # элиминационная-диета | протокол ограничения
(чист|грязн)\w+\s+(еда|еду|еды|пищ\w+|продукт\w*)  # чистая-еда | деление еды
(запрещ|разреш)[её]нн\w*\s+продукт  # запрещённые-продукты | деление еды
лишн\w+\s+вес  # лишний-вес | язык стыда
запустил\w*\s+себя  # запустила-себя | язык стыда
просто\s+(меньше|не)\s+еш  # меньше-ешь | язык стыда
сил[аыу]\s+воли  # сила-воли | язык стыда
себя\s+в\s+руки  # себя-в-руки | язык стыда

# ── 4. Штампы и кликбейт — отключаемое поштучно ───────────────────
\bшок(ир\w*|\b)  # шок | запрещённый штамп
врачи\s+(скрывают|молчат)  # врачи-скрывают | запрещённый штамп
мало\s+кто\s+знает  # мало-кто-знает | запрещённый штамп
а\s+вы\s+знали  # а-вы-знали | запрещённый штамп
сохран\w+[^.]{0,20}не\s+потерять  # сохраняйте | запрещённый штамп
ошибк\w*\s+убива  # ошибка-убивает | запрещённый штамп
гормональн\w+\s+сбо[йеия]  # гормональный-сбой | запрещённый штамп
привет,?\s+(друзья|ребят|всем)  # привет-друзья | запрещённое начало
