# content-pipeline

Контентный конвейер медицинского блога: от свежих исследований и голосовых автора до опубликованного поста в Telegram. Человек в цепочке нужен один раз — на проверке фактов, в Telegram-боте.

Собран и поддерживается через Claude Code: `CLAUDE.md` и `.claude/skills/` — рабочая конфигурация агента, `BUILD.md` — спринты, по которым он шёл. Работает на VPS в Docker.

```
PubMed ──> сбор источников ──> ранжирование тем ──┐
голосовое ──> Whisper (CPU) ──> расшифровка ──────┴─> LLM-черновик
                                                          │
                          линтер красных линий <──────────┘
                                   │
                  Telegram-бот: автор жмёт «ок» / «правка»
                                   │
                 планировщик ──> публикация в канал ──> метрики
```

## Что здесь интересного

- **Красные линии — кодом, не промптом.** `scripts/lint.py` ловит запрещённые для медблога формулировки (диагнозы, дозировки, обещания результата) до того, как материал уйдёт на проверку. Самотест — 19 кейсов.
- **Бюджет LLM с жёстким потолком.** `scripts/ai_budget.py` считает расход по ценам модели и останавливает генерацию на лимите месяца.
- **Автору не нужен git.** Единственный интерфейс автора — бот: пакет материалов раз в неделю, кнопки «ок» / «правка». Бот сам двигает файлы по статусам и коммитит.
- **Статус = папка.** `queue → review → approved → published`, переход без линтера или без ответа автора невозможен.
- **CI на настоящей базе.** GitHub Actions поднимает PostgreSQL, прогоняет 7 миграций дважды (вторая обязана быть пустой), импорт реестра тем, сборку контейнера и smoke-тест бота.

## Стек

Python 3.13 · python-telegram-bot · PostgreSQL (psycopg) · faster-whisper · OpenAI-совместимый LLM-шлюз · Docker Compose · GitHub Actions. ~7 700 строк, 103 модульных теста.

## Запуск тестов

```bash
python3 -m unittest discover -s tests -t tests
python3 scripts/selftest.py
```

Локальные скрипты работают на стандартной библиотеке. Зависимости из `requirements.txt` нужны только боту на сервере. Переменные окружения — `.env.example`.

## Что не опубликовано

Контентный план, журнал решений (`CONTEXT.md`), гайд автора и черновики материалов остались в рабочем репозитории: там личные данные соавтора. Ссылки на них в `ARCHITECTURE.md` и `BUILD.md` оставлены как есть.
