## Правила на всю сборку

**Один спринт — один сеанс.** Не начинайте следующий, не закрыв предыдущий.

**Каждый спринт заканчивается коммитом и строчкой в `CONTEXT.md`.** Если решение принято и не записано — оно потеряно.

**Не улучшать то, что уже работает.** Самый вероятный способ провалить проект — превратить его в бесконечную стройку пайплайна. После спринта 5 техничка открывается только по заявке: «я трачу N минут в неделю на X».

**Токен бота и любые ключи — в `.env`, `.env` в `.gitignore` с первого коммита.** До того, как токен вообще появится.

**Тяжёлые файлы вне гита.** Видео, футажи, экспорты монтажа — в облачную папку, в репозитории только ссылки.

6. `scripts/lint.py` — детерминированный стоп-лист. Список слов в `claude_code_setup.md`, раздел 6.2.

### Промпт для Claude Code


### Промпт для Claude Code

```

Контекст: автор — медик с 3–5 часами в неделю. Автор не

- бот упал и поднялся — состояние диалога не должно теряться
- она не ответила три дня — напоминание, но не чаще раза в день
- она прислала текст, когда бот его не ждёт
- git push отклонён из-за расхождения — pull с rebase и повтор
- pull перед каждой операцией записи, push сразу после

Токен из .env. Логи в файл, чтобы я видел, что происходило.

Начни с вопросов, если в постановке что-то неясно.
```

Она получила тестовый пакет из трёх материалов, нажала кнопки, файлы переехали, вы увидели изменения после `git pull`. Отдельно: спросили её, что неудобно, и переделали. **Это последний момент, когда переделка бесплатна.**

## Что дальше не строить

Список того, что будет хотеться сделать и чего делать не надо:

- **Автоподбор тем по метрикам.** Он потянет в сторону веса и диет, потому что там охваты. Решение о темах принимают люди раз в две недели.
- **Автопубликацию в Instagram.** Graph API требует бизнес-аккаунт и связку, риск не стоит экономии двух минут.
- **Веб-панель со статусом.** `STATUS.md` в терминале решает ту же задачу за ноль часов.
- **Автоответы на комментарии.** Общие пишет разработчик, персональные не пишет никто.
- **Генерацию сверх темпа.** Пайплайн позволит тридцать сценариев в день при плане четыре в неделю. Лишнее осядет в её очереди и встанет там.
